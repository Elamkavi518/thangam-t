🪙 Thangam — Gold Valuation & Jewelry Comparison Platform

«Know what your gold is really worth.»

Thangam is a modern gold valuation and jewelry comparison platform designed to help users understand the value of their gold, compare gold loan offers, check jewelry pricing and wastage, calculate EMI, and discover nearby jewelry stores.

The platform combines gold valuation, loan comparison, jewelry pricing, and shopping features into one simple interface.

---

✨ Features

🟡 Live Gold Rate

- View 22K and 24K gold rates
- Gold rate trend visualization
- Hourly rate refresh display
- Rate comparison based on purity

🧮 Gold Valuation Calculator

Calculate an estimated gold value using:

- Jewelry type
- Gold purity
- Weight in grams
- Current gold rate

The calculator estimates the underlying gold value before making charges, GST, or other deductions.

🏦 Gold Loan Comparison

Compare gold loan providers based on:

- Interest rate
- Loan type
- Processing fee
- Tenure
- Estimated loan amount
- Estimated repayment
- Direct contact options

The project includes sample lender data for providers such as Muthoot Finance, Manappuram Finance and SBI.

💍 Jewelry Price Comparison

Compare jewelry pricing between different stores using:

- Gold value
- Making charges
- GST
- Final estimated price
- Store contact information

⚖️ Jewelry Wastage Calculator

Estimate manufacturing wastage based on:

- Jewelry type
- Weight
- Store-specific wastage percentage
- Total gold weight charged

Wastage values are presented as store-provided/sample figures rather than values generated by Thangam.

🛍️ Jewelry Shopping Demo

The platform includes a shopping experience with:

- Product search
- Jewelry categories
- Price sorting
- Add to cart
- Buy now
- Cart management
- Mock checkout
- Order tracking
- Invoice flow
- Return request flow

The current checkout is explicitly a demo; real payments require a licensed payment gateway and live backend.

💰 EMI & Interest Calculator

Calculate:

- Monthly EMI
- Total interest
- Total repayment
- Effective interest rate
- Different loan tenures
